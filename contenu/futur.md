# Le futur
Le futur des verbes courants.

> Les mêmes fiches que l’imparfait (conjugaison.md) : un verbe et ses six formes, ou une phrase à trou (voir LISEZMOI).
> « Pièges » : des fautes propres au verbe, écrites à la personne « je » (elles finissent par -ai) : jourai, voirai…

## Niveau 5 · Dans une phrase

Phrase : Demain, nous ___ à la piscine.
Verbe : aller
Bonne : irons

Phrase : L’année prochaine, je ___ dans une autre classe.
Verbe : être
Bonne : serai

Phrase : Ce soir, tu ___ un beau cadeau.
Verbe : avoir
Bonne : auras

Phrase : Dans dix ans, ils ___ le tour du monde.
Verbe : faire
Bonne : feront

Phrase : Bientôt, vous ___ lire tout seuls.
Verbe : savoir
Bonne : saurez

Phrase : Samedi, mon cousin ___ à la maison.
Verbe : venir
Bonne : viendra

Phrase : Tout à l’heure, nous ___ un film.
Verbe : voir
Bonne : verrons

Phrase : Cet été, elles ___ le train.
Verbe : prendre
Bonne : prendront

Phrase : Quand je serai grand, je ___ courir très longtemps.
Verbe : pouvoir
Bonne : pourrai

Phrase : Dimanche, vous ___ à vos grands-parents.
Verbe : écrire
Bonne : écrirez

Phrase : Demain matin, le coq ___ très tôt.
Verbe : chanter
Bonne : chantera

Phrase : La semaine prochaine, je ___ mon livre.
Verbe : finir
Bonne : finirai

Phrase : Ce soir, tu ___ une carte à ton ami.
Verbe : envoyer
Bonne : enverras
