# Les Musiciens de Brême
Niveau : 2
Auteur : D’après les frères Grimm

Un âne était devenu trop vieux pour porter des sacs. Son maître ne voulait plus de lui. Alors il partit pour la ville de Brême : là-bas, il deviendrait musicien.

En chemin, il rencontra un chien, un chat et un coq, trop vieux eux aussi.

— Venez avec moi, dit l’âne. Nous ferons de la musique ensemble !

Le soir, ils virent une lumière dans la forêt. C’était une maison pleine de voleurs, assis devant un bon repas.

Les quatre amis eurent une idée. Le chien monta sur l’âne, le chat sur le chien, et le coq sur le chat. Puis ils se mirent à chanter tous ensemble : l’âne se mit à braire, le chien à aboyer, le chat à miauler et le coq à chanter.

Quel vacarme ! Les voleurs crurent voir un monstre et s’enfuirent dans la forêt.

Les animaux mangèrent le repas et s’installèrent dans la maison. Ils s’y trouvèrent si bien qu’ils n’allèrent jamais jusqu’à Brême.

## Questions

Question : Pourquoi l’âne part-il de chez lui ?

Mauvaise : Il veut voir la mer

Mauvaise : Il cherche ses parents

Question : Que font les animaux pour chasser les voleurs ?
Bonne : Ils chantent tous ensemble
Mauvaise : Ils se cachent sous la table
Mauvaise : Ils appellent les gendarmes
Mauvaise : Ils ferment la porte à clé

Question : Où vivent les quatre amis à la fin ?
Bonne : Dans la maison des voleurs
Mauvaise : Dans la ville de Brême
Mauvaise : Dans une ferme
Mauvaise : Dans une grotte
