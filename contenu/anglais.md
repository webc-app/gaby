# Anglais
Mots et petites phrases en anglais.

> Deux sortes de fiches. Un mot : Image (un emoji, un nombre ou un mot français), Anglais, Français. Les mauvaises réponses sont prises dans le même groupe (###).
> Un dialogue : Question (en anglais), Bonne, 3 Mauvaise, Sens (la question en français).
> Après une modification de l’anglais : lancer « npm run voix » pour enregistrer les nouveaux sons.
