# Problèmes
Lire un petit problème et trouver la réponse.

> Les mêmes fiches que le Code de la route : Question, Bonne, 3 Mauvaise, Explication facultative (voir LISEZMOI).
> Pas de prénom : un pirate, un fermier, « je ».
> Une seule lecture possible, avec le moins de mots possible : « il en trouve 3 autres », « 7 euros chacun ».
