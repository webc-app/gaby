# Panneaux du code de la route

Modèles officiels des signaux routiers français, publiés au format SVG par le Cerema (Équipements de la route) :
https://equipementsdelaroute.cerema.fr/signaux-au-format-svg-a654.html. Nettoyés pour l'app : viewBox gardée, dimensions fixes et données d'Inkscape retirées.

Le nom du fichier est celui qu'on écrit dans les fiches (`Image : panneau stop`). Code officiel de chacun :
stop AB4 · sens-interdit B1 · cedez AB3a · pietons C20a · danger A14 · enfants A13a · velo-interdit B9b ·
piste-cyclable B22a · 30 B14 · 50 B14 · stationnement-interdit B6a1 · virage A1a · feux A17 ·
attention-pietons A13b · cyclistes A21 · glissant A4 · animaux A15a1 · priorite-a-droite AB1 · route-prioritaire AB6 ·
rond-point AB25 · circulation-interdite B0 · depasser-interdit B3 · pietons-interdits B9a · tout-droit B21b ·
chemin-pietons B22b · zone-30 B30 · aire-pietonne B54 · parking C1a · sens-unique C12 · ralentisseur C27 ·
piste-conseillee C113 · voie-verte C115 · autoroute C207 · arret-bus C6.

Les feux rouge et vert (`feu-rouge`, `feu-vert`) ne sont pas des panneaux : ils sont dessinés par l'app (Visuel.svelte).
